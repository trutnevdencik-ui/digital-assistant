# Цифровое лицо — локальный ИИ

Пробное Android-приложение с голосовыми помощниками Артёмом и Алисой.

## Возможности
- Голосовое общение
- Два голосовых помощника
- Распознавание речи
- Озвучивание ответов
- Интерфейс исходного проекта

## Android APK
Приложение собирается автоматически через GitHub Actions.

## Статус
Первая тестовая версия в разработке.
