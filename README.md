# Цифровое лицо — Android APK

Этот репозиторий содержит Android WebView-оболочку для существующего HTML-интерфейса и GitHub Actions workflow для сборки debug APK. Исходный интерфейс помещён в `app/src/main/assets/index.html` без переработки дизайна.

## Сборка APK с телефона через GitHub

1. Загрузи **содержимое этой папки** в корень репозитория `digital-assistant` (с сохранением папки `.github`). Не загружай ZIP вместо распакованных файлов.
2. Убедись, что файл `.github/workflows/build-apk.yml` появился в репозитории.
3. Открой вкладку **Actions**. Выбери **Build Android APK**.
4. Нажми **Run workflow** (или дождись автоматической сборки после отправки изменений в `main`).
5. После успешной сборки открой запуск workflow и скачай артефакт `digital-assistant-debug-apk`. Внутри будет `app-debug.apk`.
6. Открой APK на Android и разреши установку из этого источника, если телефон попросит.

## Важно: что уже есть и чего пока нет

- Это Android-оболочка для существующей страницы; она не заменяет и не переписывает интерфейс.
- Включены JavaScript, локальное хранилище WebView и запрос разрешения на микрофон. Реальная работа распознавания речи зависит от поддержки SpeechRecognition в установленном Android WebView и системной службы распознавания.
- HTML обращается к серверу по адресам `/api/chat` и `/api/tts`. **Собственный ИИ-сервер в этом комплекте пока не реализован**, поэтому сам APK не станет автономным ИИ только после сборки. Пока сервер не подключён, запросы к ИИ не будут работать; системная озвучка браузера может работать отдельно.
- Для подключения будущего HTTPS API измени `window.ASSISTANT_API_BASE` в `app/src/main/assets/assistant-config.js`. Сервер должен реализовать `POST /api/chat` и, если нужна нейроозвучка, `POST /api/tts`, а также разрешать CORS для origin приложения `https://appassets.androidplatform.net`. Не помещай секретные ключи в HTML или этот файл.
- Два самостоятельных нейроголоса Артёма и Алисы, локальная языковая модель и полностью автономная работа без сервера — следующие отдельные этапы. Этот комплект их не имитирует.

- Android package: `com.digitalassistant.app`
- minSdk: 23 (Android 6.0)
- targetSdk / compileSdk: 35
- Java: 17; Gradle: 8.9; Android Gradle Plugin: 8.7.3; Kotlin: 2.0.21
